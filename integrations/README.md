# Integrations

This public snapshot ships one verified hardware integration:

- [`raspberry-pi/`](raspberry-pi/) turns a Raspberry Pi 4 into a Bluetooth HFP voice-conversion headset. A USB headset supplies capture and playback, while the phone receives converted microphone audio.

The integration uses `@convbased/sdk` as a workspace dependency and includes setup, service units, tests, operations, validation, and security guidance.
